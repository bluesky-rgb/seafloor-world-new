# 项目总结

## 目标

用一个浏览器里就能打开的三维场景，把海洋“大、诡秘、物种丰富”的特点展示出来。约束是：**每个场景都基于真实地点和实测数据，画面上的现象尽量由物理规律算出来，而不是凭感觉画出来**。凡是为了看得清做的放大或简化，都在页面上写明。

## 现在的规模

| 项目 | 数量 |
| --- | --- |
| 真实地点 | 19 个固定地点 + 2 条下潜路线（关岛 → 马里亚纳海沟、重走 2012） |
| 图鉴生物 | 103 种 |
| 探险任务 | 13 个 |
| 物理实验 | 3 个（深海声道、压力、全球海底地形） |
| 页面内更新记录 | 30 次 |
| 引用资料 | 68 条（见 [SOURCES.md](SOURCES.md)） |
| 代码 | 约 4,850 行 JavaScript，按功能分成 43 个源文件，纯静态网站 |

## 用到的物理与生态模型

| 现象 | 做法 |
| --- | --- |
| 水下光线与颜色 | 按红、绿、蓝三个波段分别做 Beer–Lambert 衰减，水质决定衰减系数；视距、光柱、斯涅尔窗、人眼适应 |
| 潮汐 | 半日潮余弦曲线，周期 12.42 h，潮差简化为 4 m；岩岸整体随潮位升降，藤壶只在淹没时伸出蔓足 |
| 波浪与海流 | 线性波浪理论（色散关系）求波长和水质点轨道速度，海流按对数剖面；驱动巨藻摆动、沙纹和漂流 |
| 冰缘光照 | 冰下只透进约 3% 的光，越靠近冰缘、越往深处，从开阔水侧向漫进来的光越多；气泡、相机和光柱都按同一条冰缘曲线判断 |
| 温泉折射 | 温水与冷水密度不同造成的“抖动”：把温泉位置投影到屏幕，在后期处理中做局部波纹扰动 |
| 气泡 | 按水温黏度计算上升速度，按玻意耳定律随深度膨胀 |
| 压力 | 静水压强；泡沫杯按泡孔被压塌的模型缩小，水的压缩率 4.6×10⁻¹⁰ /Pa |
| 深海声道 | Mackenzie (1981) 声速公式加实测温度剖面，按斯涅尔定律追踪 25 条声线 |
| 昼夜垂直迁移 | 动物追随固定亮度的等光面上下移动，限制游速 |
| 海底盐池 | 两种液体界面上的内波（约化重力 g′ ≈ 0.30 m/s²），菲涅尔反射 |
| 蓝洞分层 | 按实测深度的溶氧、硫化氢和浑浊层 |
| 生物发光 | 水流剪切应力超过约 0.15 Pa 才触发闪光 |
| 自由驾驶 | 推进力、二次阻力、海流与波浪漂移、60 m 缆绳 |
| 全球地形 | NOAA ETOPO 20 角分数据，双线性插值画地形图和剖面 |
| 生物分布 | 每种生物有深度、水温和生境范围，场景按这些条件决定出现谁 |

## 交互功能

- **展览模式**：约 8 分钟的自动导览，走过 16 个地点后一路下潜到海沟底，配字幕和 MiniMax 语音讲解。
- **自由探索**：拖动转视角，点击生物识别；环境参数（深度、水温、水质、波浪、海流、昼夜、手电）都可以自己调。
- **自由驾驶**：键盘或手机摇杆开着水下机器人游动。
- **探险任务与图鉴**：13 个任务带进度和“前往”按钮；遇见过的生物才显示名字。
- **触碰发光**：在黑暗的水里划水，浮游生物按剪切力闪光。
- **物理实验**：深海声道、压力实验、全球海底地形图与剖面。
- **明信片**：把当前画面做成带地点、深度、水温、气压的图片。
- **VR**：手机分屏立体（纸盒眼镜）和 WebXR 头显模式。
- **流畅模式**：手机默认降低分辨率、关闭泛光、减少重复生物；电脑上卡顿时自动切换。
- **说明文字**：欢迎卡、“玩法说明”、每个地点的介绍和看点、页面内的更新记录与资料来源。

## 技术结构

- 纯静态网页：three.js r128（CDN 加载）+ 自写的 WebGL 着色器补丁，实现水下光学、焦散、光柱等效果。详见 [技术实现说明](ARCHITECTURE.md)。
- 后期处理链：渲染 → 泛光 → 白平衡、暗角与雾化。
- 源码按功能分成 43 个文件，用一个只依赖 Python 的小脚本拼接成页面加载的脚本；GitHub Pages 直接托管仓库根目录。
- 每次推送自动检查：生成的脚本与源码一致、语法正确、讲解词与音频对应、文档与页面同步。
- `tools/build_single.py` 把所有文件合并成一个 HTML，用于在 Claude 里发布同一个页面。Claude 版本额外有“所有访客共享的图鉴”。

## 开发方式

功能按路线图逐项加入。每加一项，都会：

1. 先查资料，确定真实地点、深度和参数；
2. 在浏览器里截图检查画面，修正看不清或不符合物理的地方；
3. 在页面上补充说明文字，并在页面内的更新记录、路线图和资料来源里登记。

完整过程见 [CHANGELOG.md](CHANGELOG.md) 和 [ROADMAP.md](ROADMAP.md)。

## 已知限制

- **画面是简化的三维造型**：为了在手机浏览器里流畅运行，生物和地形没有精细贴图和骨骼动画，一眼能看出是模型而不是实拍。
- **模型是简化的**：鱼群用群游规则，水流用解析公式，不是真正的流体模拟。
- **地形分辨率有限**：全球地图网格约 37 km，海沟在地图上只显示约 9,000 m 深（真实 10,935 m）。场景近景不受影响。
- **没有在真机上完整验证**：测试主要在电脑模拟的浏览器里进行，手机性能、陀螺仪和 VR 头显需要真机试用。
- **只有中文界面**。
