研究思路

先找到真实的地方，再让物理来画

项目的出发点是把海洋“大、诡秘、物种丰富”的样子展示出来，但不靠想象去画。每加一个场景，都按同一套流程走一遍。

  1. 选一个真实地点和一个现象

    例如南海西沙的珊瑚礁、戴维森海山脚下的章鱼花园、北极的浮冰边缘。地点要有公开的考察记录，现象要能讲清楚一个道理（光怎样消失、潮汐怎样分带、温泉怎样缩短孵化期）。

  2. 查资料，把文字变成参数

    水深、水温、水质、浪高和周期、海流、太阳高度，以及生物的种类、大小、颜色和密度。数字都来自论文、保护区资料、考察机构和百科，在“资料库”里逐条列出。

  3. 用物理模型算出画面

    同一套水下光学、波浪和生态规则用于所有场景：换一个地点，只是换参数。生物出现在哪里，由它的深度、水温和生境范围决定，而不是手工摆放。

  4. 搭场景、做生物

    地形、生物造型和动画都在代码里生成，没有外部贴图和模型文件，所以整个网站是纯静态的，打开即用。

  5. 截图检验，对照照片修改

    每个场景都在浏览器里截图检查：颜色是否像真实水下照片、生物比例是否对、有没有看不清或穿模的地方。不对就改参数或造型，再截一次。

  6. 写说明，标注简化

    每个功能都配中文说明；凡是为了看清而放大的、为了性能而简化的、找不到实测值只能估计的，都在页面上写明。

  7. 讲解、检查、发布

    展览模式的讲解词由 MiniMax 语音模型在 GitHub 上自动配音；每次提交自动检查构建、讲解与音频的对应、文档同步，再发布到 GitHub Pages。

技术架构

一个纯静态网站，加两条自动化流程

三维场景

three.js r128 · WebGL

自写的着色器补丁 waterify() 给所有材质加上水下光学：按红绿蓝三个波段衰减、散射背景、手电锥光、焦散和沙纹。

源码

src/ · {{N_SRC}} 个文件

按功能拆分（光学、海底、鱼群、各个地点、界面、导览……），由 tools/build.py 拼成页面加载的 js/seafloor.js，只依赖 Python。

后期处理

渲染 → 泛光 → 白平衡

半浮点精度渲染，泛光让生物发光有光晕，最后做白平衡、暗角、手电光晕和温泉上方的折射扰动。流畅模式会关掉泛光。

语音讲解

narration/tour.json → MiniMax

讲解词一改，GitHub Actions 就调用 MiniMax 语音合成生成 mp3 并提交回仓库。密钥只存在仓库的加密变量里，网页只播放生成好的音频。

自动检查

tools/check.py · smoke_test.py

每次推送检查构建是否最新、语法、讲解与音频是否对应、文档是否同步；本地用无头浏览器跑场景、导览、地图、明信片、VR 和驾驶。

发布

GitHub Pages · Claude 页面

仓库根目录直接作为网站。另有一个把所有文件合成单个 HTML 的版本，发布在 Claude 里，带所有访客共享的图鉴。

遗留问题

还没做好、或者做不了的地方

下面每一条都说明了原因，以及要解决需要什么。标着“需要你”的几条，单靠写代码完成不了。

需要你

真实的海洋录音

现在的声音是用 Web Audio 合成的：浪声、呼吸与气泡、抹香鲸的咔嗒声、深海低鸣。真实录音（鲸歌、珊瑚礁的噼啪声、冰下海豹的叫声）会大大增强沉浸感，但录音有版权，不能随意下载使用。

提供允许使用的录音文件（自己录的，或明确标注可商用/可署名使用的，例如部分 NOAA、MBARI 公开声学数据），我负责剪辑、按地点和深度混音、加上来源说明。

翻译

英文版的剩余部分

界面、地点介绍、图鉴、信息卡、任务、讲解词（含英文配音）和本总览页都已有英文版（地址后加 ?lang=en，或点右上角 English）。页面内每次更新的详细说明、仓库里的 Markdown 文档仍只有中文，英文译文是机器辅助加人工校对，可能有不够地道的地方。

如果有母语为英文的读者，请他们看一遍，把别扭的句子告诉我。

需要真机

手机、陀螺仪和 VR 头显的实测

测试都在电脑上的无头浏览器里跑。已经加了流畅模式和卡顿自动切换，但不同手机的性能、陀螺仪方向和 WebXR 头显的表现，需要在真机上试。

用你的手机（以及有的话 VR 头显）打开网站试一遍，把卡顿或看不懂的地方告诉我。

画质

生物仍是代码生成的简化造型

为了在手机上流畅运行、不依赖外部文件，生物都是用几何体拼出来的，没有贴图和骨骼动画，一眼能看出是模型。章鱼、马尾藻等造型偏卡通。

如果要更逼真，可以换成带骨骼动画的 glTF 模型。需要找到授权合适的模型（或请人制作），并接受网页体积变大。

数据

部分数值是估计

北极浮冰边缘的水深取约 300 m、南麂列岛的潮差简化为 4 m，没有找到实测值；全球地形图的网格约 37 km，海沟在图上只显示约 9,000 m 深。这些都已在页面上注明。

如果能找到当地的实测资料（例如潮汐表、测深图），可以替换成准确数值。

模型

物理是简化模型，不是数值模拟

鱼群用群游规则，水流和波浪用解析公式，光学只分红绿蓝三个波段，没有真正的流体和辐射传输计算。对于展示和教学足够，但不能当科研工具用。

保持现状即可；如果某个现象需要更精确，可以针对它单独做（例如用实测光谱代替三个波段）。

审阅

内容没有经过海洋学专家审阅

所有说明文字都对照了公开资料，但没有请专业人士逐条把关。

如果要用于课堂或展览，建议请海洋生物或海洋物理方向的老师看一遍图鉴和地点介绍。

无障碍

还没有真正的读屏用户试过

“文字描述”（G 键）会列出当前地点、环境读数和附近看得见的生物，并说出每种生物相对视线的方向和距离；画面选中后可以用方向键转动视角、+/− 缩放，面板和导览都能用键盘操作。这些都只在自动测试里验证过。

请一位使用读屏软件（如 VoiceOver、NVDA）的朋友试一遍，告诉我们哪里读不顺、缺什么。
